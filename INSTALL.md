# Installing vhs-decode (Nix)

The recommended installation method is via Nix flakes.

## Requirements

- Nix with flakes enabled

## Install and run

- Build and run the default package:
  - `nix run`

## Install to your profile

- Install the package to your user profile:
  - `nix profile add .`

This provides the following commands on your PATH:
- `ld-decode`
- `ld-cut`
- `ld-compress`
- `ld-ldf-reader-py`
- `ld-lds-converter-py`

The external programs these commands call are supplied by the package itself,
so they do not need to be installed separately: `flac` 1.5.0 or later, which
`ld-compress` uses for multithreaded encoding, and `ffmpeg`, which `ld-decode`
uses to read the input formats PyAV does not cover and to resample with
`--inputfreq`.

## Verify installation

- Check versions:
  - `ld-decode --version`
  - `ld-cut --version`
  - `ld-compress --version`
  - `ld-ldf-reader-py --version`
  - `ld-lds-converter-py --version`

These commands report the version generated by the flake build.
